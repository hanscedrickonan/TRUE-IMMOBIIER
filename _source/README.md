# Sources du site True Immobilier

- `logo-original.jpg` : le logo fourni.
- `logo_shape.py` : redessine le symbole du logo en vecteur (objet en verre + logo du header).
- `site.json` : le brief (textes, couleurs, chiffres) utilisé pour générer le site.

Le site généré est à la racine du dépôt. Pour une petite correction, modifiez directement
`index.html`, puis lancez `python3 build_monofichier.py` pour mettre à jour la version monofichier.
